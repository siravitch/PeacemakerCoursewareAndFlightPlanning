# AU-23A Flight Training & Mission Planning

เครื่องมือฝึกและวางแผนภารกิจสำหรับ AU-23A (ฝูง ๕๐๑ บน.๕) — Mission Planner, Navigation, Weight & Balance, Courseware, IFR Trainer

> **ใช้เพื่อการฝึกเท่านั้น** ไม่ใช่เอกสารทางการ ตรวจสอบกับ T.O. / AIP / NOTAM ก่อนใช้งานจริงเสมอ

## เปิดใช้งาน
เปิดลิงก์ GitHub Pages ของ repo นี้ (Settings → Pages) หรือเปิดไฟล์ `index.html` ด้วย Chrome โดยตรง

## วิธีอัปเดตเวอร์ชัน
1. เปิด repo → **Add file → Upload files**
2. ลากไฟล์ `index.html` ใหม่มาทับชื่อเดิม
3. กด **Commit changes** แล้วรอ 1–2 นาที ทุกคนจะได้เวอร์ชันใหม่

ประวัติทุกเวอร์ชันอยู่ในแท็บ **Commits** (ย้อนกลับได้)

> อย่าเปลี่ยนชื่อ repo เพราะข้อมูลที่ผู้ใช้บันทึกไว้ในเครื่องผูกกับลิงก์เว็บ
