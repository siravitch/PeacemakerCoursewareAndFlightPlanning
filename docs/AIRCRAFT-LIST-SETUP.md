# ตั้งค่าบทบาท (Roles) และรายการน้ำหนักเปล่าของเครื่อง (Aircraft Empty Weights)

ทุกคนที่เปิดเว็บเห็นรายการน้ำหนักเปล่าเดียวกัน บทบาทมี 3 แบบ ผู้ใช้ทุกคนใช้ callsign + PIN เดิมของตนเอง ไม่มีรหัสเพิ่ม

| บทบาท | ใช้งานโปรแกรม | แก้ Aircraft Empty Weight | รีเซ็ต PIN / ลบ callsign |
|---|---|---|---|
| นักบินฝูง (pilot) — ทุกคนที่ลงทะเบียน ไม่ต้องตั้งค่าอะไร | ✓ (ข้อมูลของตนเองเท่านั้น) | ✗ อ่านและเลือก "Use" ได้ | ✗ |
| นักบินลองเครื่อง (`testpilots`) | ✓ | ✓ | ✗ |
| แอดมิน (`admins`) | ✓ | ✓ | ✓ |

## ขั้นตอนครั้งเดียว (ผู้ดูแลระบบ ใน Firebase console)
1. **Firestore Database → Rules**: ลบของเดิมทั้งหมด วางเนื้อหาไฟล์ `firestore.rules` ฉบับใหม่ทั้งหมด แล้วกด **Publish**
2. **Firestore Database → Data → Start collection**
   - Collection ID: `config`
   - Document ID: `roles`
   - Field 1: ชื่อ `admins` ชนิด **array** ใส่ค่า (ชนิด string) เป็น callsign ของแอดมิน **ตัวพิมพ์ใหญ่** เช่น `VOODOO`
   - Field 2: ชื่อ `testpilots` ชนิด **array** ใส่ callsign ของนักบินลองเครื่อง (ถ้ายังไม่มี ใส่ array ว่างได้ — หรือเพิ่ม string ว่างหนึ่งค่า ถ้าคอนโซลไม่ให้สร้าง array ว่าง)
   - กด Save
3. ให้นักบินลองเครื่องหรือแอดมินเปิดเว็บ → ลงชื่อเข้าใช้ → แท็บ Aircraft Empty Weights → กด **Publish this list as the shared list** (ครั้งแรกครั้งเดียว: ส่งรายการ 12 ลำที่มีในโปรแกรมขึ้นเซิร์ฟเวอร์)

แอดมินต้อง **ลงทะเบียน callsign ของตนในเว็บก่อน** (และใช้ PIN 8 หลัก) แล้วจึงใส่ชื่อในรายการ `admins`

## เพิ่ม / ถอด บทบาท
แก้ฟิลด์ `admins` / `testpilots` ของเอกสาร `config/roles` (callsign ตัวพิมพ์ใหญ่ ตรงกับที่ลงทะเบียน) — มีผลภายในไม่กี่นาที (หน้าเว็บอ่านรายชื่อทุกครั้งที่ซิงก์รายการเครื่อง และเมื่อเปิดหน้า) บทบาทแก้ได้ที่ Firebase console เท่านั้น ในโปรแกรมแก้ไม่ได้ (ตั้งใจ)

## เครื่องมือแอดมิน (แสดงเฉพาะแอดมิน: กดชิป callsign → ส่วน "Administrator · ผู้ดูแลระบบ")
- **Reset PIN** — ลบเฉพาะ PIN ของ callsign นั้น น้ำหนักและข้อมูลยังอยู่ เจ้าของลงทะเบียนใหม่ด้วย PIN ใหม่ได้ทันที (ใช้เมื่อลืม PIN)
- **Delete** — ลบ callsign ทั้งหมด: PIN, น้ำหนักในรายชื่อ และข้อมูลที่ซิงก์ไว้ทั้งหมด กู้คืนไม่ได้ (ใช้กับคนที่ลงทะเบียนซ้ำ 2 รอบ)
- ทั้งสองปุ่มกดสองครั้ง (ครั้งแรกถามว่า "Sure?") และใช้กับตัวเอง / แอดมินคนอื่นไม่ได้ ถ้าจะลบแอดมิน ให้ถอดชื่อออกจาก `admins` ใน console ก่อน
- ช่อง Callsign ด้านล่างใช้พิมพ์ callsign เองได้ (กรณีไม่ขึ้นในรายชื่อ)
- ร่องรอย: เอกสาร `ops/adm-<CALLSIGN>` เก็บ "ใคร (by) ทำอะไร (a) เมื่อไร (t)" ครั้งล่าสุดต่อ callsign เท่านั้น (ไม่ใช่ log ครบ)

## ข้อควรรู้
- ลบลำที่ editor กด "ลบ" = ทำเครื่องหมาย `x: true` ในเอกสาร (ไม่ได้ลบจริง) เปิด Firestore ดูย้อนหลังได้ มีช่อง `by` (ใคร) และ `t` (เมื่อไร) ทุกรายการ
- ถ้าสองคนแก้ลำเดียวกันพร้อมกัน ฉบับที่บันทึกทีหลังชนะ
- ผู้ที่ไม่ใช่นักบินลองเครื่อง/แอดมินอ่านและเลือก "Use" ได้ แก้ไม่ได้ (ฟอร์มและปุ่มแก้ถูกซ่อน และกฎฝั่งเซิร์ฟเวอร์ปฏิเสธด้วย)
- เมื่อผู้มีสิทธิ์แก้น้ำหนักของลำที่คนอื่นเลือกใช้อยู่ในการคำนวณ ค่าในหน้าคนนั้นจะอัปเดตตามอัตโนมัติ (ถ้าเขาไม่ได้แก้ตัวเลขเอง) พร้อมข้อความแจ้ง
- ความปลอดภัยอาศัย PIN 4–8 หลัก ซึ่งเดาได้ถ้าลองซ้ำ ๆ — แอดมินควรใช้ PIN 8 หลัก ถ้า PIN แอดมินหลุด ผู้อื่นลบ callsign ของคนอื่นได้ ควรเปลี่ยนด้วยการถอดชื่อออกจาก `admins` ทันที
- ไม่มี `config/roles` = ไม่มีใครเป็นแอดมินหรือนักบินลองเครื่อง (ทุกคนเป็นนักบินฝูง) และรายการน้ำหนักกลางยังไม่เปิดใช้
