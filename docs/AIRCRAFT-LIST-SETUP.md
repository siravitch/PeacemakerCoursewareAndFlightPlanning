# ตั้งค่ารายการน้ำหนักเปล่าของเครื่อง (Aircraft Empty Weights) ให้เป็นข้อมูลกลาง

ทุกคนที่เปิดเว็บเห็นรายการเดียวกัน แก้ไขได้เฉพาะ callsign ที่อยู่ในรายชื่อ **editors** (นักบินลองเครื่อง) — ผู้แก้ใช้ callsign + PIN เดิมของตนเอง ไม่มีรหัสเพิ่ม

## ขั้นตอนครั้งเดียว (ผู้ดูแลระบบ ใน Firebase console)
1. **Firestore Database → Rules**: วางเนื้อหาไฟล์ `firestore.rules` ฉบับใหม่ทั้งหมด แล้วกด **Publish**
2. **Firestore Database → Data → Start collection**
   - Collection ID: `config`
   - Document ID: `editors`
   - Field: ชื่อ `list` ชนิด **array** ใส่ค่า (ชนิด string) เป็น callsign ของนักบินลองเครื่อง **ตัวพิมพ์ใหญ่** เช่น `VOODOO`, `BLUE1`
   - กด Save
3. ให้ editor เปิดเว็บ → ลงชื่อเข้าใช้ → แท็บ Aircraft Empty Weights → กด **Publish this list as the shared list** (ครั้งแรกครั้งเดียว: ส่งรายการ 12 ลำที่มีในโปรแกรมขึ้นเซิร์ฟเวอร์)

## เพิ่ม / ถอด editor
แก้ฟิลด์ `list` ของเอกสาร `config/editors` (callsign ตัวพิมพ์ใหญ่ ตรงกับที่ลงทะเบียน) — มีผลภายในไม่กี่นาที (หน้าเว็บอ่านรายชื่อทุก 3 นาทีและเมื่อเปิดหน้า)

## ข้อควรรู้
- ลบลำที่ editor กด "ลบ" = ทำเครื่องหมาย `x: true` ในเอกสาร (ไม่ได้ลบจริง) เปิด Firestore ดูย้อนหลังได้ มีช่อง `by` (ใคร) และ `t` (เมื่อไร) ทุกรายการ
- ถ้าสอง editor แก้ลำเดียวกันพร้อมกัน ฉบับที่บันทึกทีหลังชนะ
- ผู้ที่ไม่ใช่ editor อ่านและเลือก "Use" ได้ แก้ไม่ได้ (ฟอร์มและปุ่มแก้ถูกซ่อน และกฎฝั่งเซิร์ฟเวอร์ปฏิเสธด้วย)
- เมื่อ editor แก้น้ำหนักของลำที่คนอื่นเลือกใช้อยู่ในการคำนวณ ค่าในหน้าคนนั้นจะอัปเดตตามอัตโนมัติ (ถ้าเขาไม่ได้แก้ตัวเลขเอง) พร้อมข้อความแจ้ง
